# What is the Metric System?

**Definition:** The metric system is an internationally agreed decimal system of measurement originally developed in France during the late 18th century. It uses a standard set of base units (such as the meter for length and the gram for mass) and relies on base-10 prefixes (like kilo-, centi-, and milli-) to scale measurements up or down effortlessly.

## How Does the Metric System Work?
Because the metric system is a base-10 (decimal) system, converting between units simply requires moving the decimal point left or right. The system uses standardized prefixes to denote scale:
- **Kilo-**: 1,000 times the base unit
- **Centi-**: 1/100th of the base unit
- **Milli-**: 1/1,000th of the base unit

For instance, 1 kilometer is exactly 1,000 meters, and 1 meter is exactly 1,000 millimeters.

## Real-World Example in Global Trade
When an electronics manufacturer in Japan ships components to an assembly plant in Germany, they rely entirely on the metric system. Using a unified system ensures that tiny components, measured in precise millimeters, fit perfectly into housings designed halfway across the world without complex translation errors.

## Metric System vs Imperial System

| Feature | Metric System | Imperial System |
|---------|---------------|-----------------|
| **Base Logic** | Base-10 (Decimal) | Arbitrary historical fractions |
| **Global Adoption** | Used by ~95% of the world | Primarily used in the USA |
| **Ease of Conversion**| Simple decimal shift | Complex fractional math |
