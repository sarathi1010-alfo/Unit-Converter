## How Do Significant Figures Work?
When performing a calculation or conversion, the result should not be more precise than the least precise measurement used. For example, if a measurement has 3 significant figures, the converted output should generally be rounded to reflect that same level of precision.

## Real-World Example in Chemistry
In a lab, if a scale only measures to the nearest tenth of a gram (e.g., 12.5 g), converting that to milligrams and reporting it as 12500 mg implies an exactness that the original scale didn't have. Using sig figs ensures the integrity of the data.

## Precision vs Accuracy
| Term | Definition |
| --- | --- |
| Precision | How close multiple measurements are to each other (reflected by sig figs). |
| Accuracy | How close a measurement is to the true or accepted value. |
